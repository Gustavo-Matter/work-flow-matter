# Diagnóstico do ambiente — 15/10/2026

O contexto que o Claude Code carrega em toda sessão, em qualquer projeto da Matter.

| Camada | O que tem | Problema |
|---|---|---|
| `~/.claude/CLAUDE.md` (global) | Padrões Matter para Python, Node e Go; Linear | Não tem nada de .NET nem de Flutter, que são as stacks em uso. Regra de stack carregada em toda sessão, até quando não se aplica. |
| Memória (`MEMORY.md` + claude-mem) | Notas de projeto + injeção automática de observações | Duas memórias paralelas fazendo a mesma coisa. |
| Plugins / MCP | claude-mem, Figma, Canva, Notion, Linear, design, pdf… | Cada servidor soma definições de ferramenta ao contexto, mesmo sem uso. |
| `.claude/settings.local.json` dos repos | Permissões aprovadas uma a uma | Viraram lista de comandos únicos (curl com payload, caminhos de scratchpad de sessões antigas). |
| Worktrees | `docs/diretrizes-linear` e `docs/planejamento-features` | Ficam em `AppData\Local\Temp\claude\…\scratchpad`. Uma limpeza do Temp some com o diretório e deixa worktree órfão. |
| Processo (Linear) | `~/.claude/linear/DIRETRIZES.md` + skill `linear-tarefa` | Copiado também para uma branch `docs/diretrizes-linear` em **cada** repositório. |

Correções: [ADR-0001](../adr/0001-plugin-distribui-o-workflow.md), [ADR-0005](../adr/0005-regra-de-stack-em-skill.md) e a regra 7 do [workflow](../workflow.md).
